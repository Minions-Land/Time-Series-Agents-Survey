# Editable survey figures

44 deduplicated, single-slide PowerPoint files copied from the desktop handoff collection on 2026-10-15.

- `01_时序综述图件`: 24 survey figures.
- `02_RSI参考模板`: 6 reference templates.
- `03_历史不同构图`: 14 distinct historical layouts.

Native shapes, text, and groups are preserved. Independent bitmap logos remain bitmap assets. Reference templates and historical layouts are editing resources, not assertions of the current survey taxonomy. The authoritative taxonomy and evidence are maintained in the classification ledger.

The desktop `Survey Figures` directory contains PPT files only. Source mapping and validation receipts are in `artifacts/figure_collection_20261015/`. Non-PPT desktop material and superseded copies were moved to a local, Git-ignored backup before cleanup.

These editable sources are managed on GitHub. Overleaf receives only the manuscript compilation files and figure exports used by LaTeX.
