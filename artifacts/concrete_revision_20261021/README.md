## Editing

All ten decks contain native editable shapes and nested groups, with no embedded raster illustrations. Ungroup the complete figure to reach semantic modules, then ungroup modules or icons as needed. Figure 8 was exercised in Microsoft PowerPoint through two levels of ungroup and undo. All ten decks passed package, geometry, and Artifact Tool import checks and were rendered for visual inspection. PDF fonts are Times New Roman.

Icon sources reuse Lucide line icons from the existing figure work and lucide-static 0.468.0 (https://lucide.dev). License: ISC, see `LUCIDE_LICENSE.txt`. Previous figure versions are retained in their original directories.
