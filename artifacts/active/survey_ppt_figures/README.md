# Editable survey figure decks

These are copies of the grouped PowerPoint figure decks used during the survey work. Originals remain in their existing locations. Each listed deck contains at least one native PowerPoint group (`p:grpSp`) and can be grouped/ungrouped in PowerPoint.

Decks with `embedded_pictures > 0` retain a raster reference component inside a group; the surrounding layout is groupable, but the raster itself is not decomposed into editable shapes.

See `MANIFEST.csv` for source paths and component counts.
