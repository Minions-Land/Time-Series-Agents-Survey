# 综述配图 PPT

RSI 扇形图请使用 `RSI_landscape_all_elements_grouped.pptx`（原 `rsi_landscape__RSI_landscape_editable_grouped_nocaption.pptx` 已替换为同一版本）。

主体选择后取消组合即可编辑独立文字、年份、扇形、弧线、分界线和 Logo；标题与副标题单独可编辑。共 135 个原生形状/文本对象、32 个独立 Logo 图片，无整幅底图。Logo 经图像分离处理，与低分辨率原图有细节差异；Logo 内部笔画不是原生矢量。

此前仅凭存在 `p:grpSp` 判定所有旧文件已逐元素拆分并不充分。其他旧图稿仍需逐个审查，不能据此声称全部已逐元素可编辑。

`MANIFEST.csv` 记录来源及对象数量。
