# Editable survey figures

This revision uses restrained graphite, steel grey, and muted red accents, with separate pictorial assets and shallow shadows. Each PowerPoint contains one figure on one slide. Related objects are nested in groups; ungroup to edit labels, connectors, tables, and individual icons. Icon interiors are raster artwork rather than editable vector paths.

## Files

- `pptx/`: one editable PowerPoint per revised figure.
- `pdf/`: manuscript exports. Captions remain in `main.tex`.
- `source/`: generated compositions used as the source for component extraction. These are visual drafts, not authoritative scientific diagrams.
- `prompts/`: composition specifications.
