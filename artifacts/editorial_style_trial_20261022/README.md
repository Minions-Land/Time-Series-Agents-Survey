# Editorial style trial: Figures 4, 7 and 9

Three standalone, one-slide PPTX copies compare a restrained visual treatment against the existing manuscript figures. This trial leaves main.tex and the production figure references unchanged.

- Arial headings and labels, dark neutral text.
- Black data traces, without drop shadows.
- Neutral structural connectors; navy and terracotta identify selected temporal, action and review relationships.
- Existing icon crops retained, recolored with editable PowerPoint picture effects.
- Native tables, curves, text and nested groups preserved. Original raster icon interiors remain raster.

The three-page comparison PDF places the current figure on the left and the trial on the right. Individual figure PDFs are exported from the finalized PPTX. All three PPTX files passed package, geometry and import checks; Figures 4 and 7 retain native tables.

Scripts: restyle.py applies the treatment; compare.py creates the comparison PDF. provenance.json records the source presentations and retained groups.
