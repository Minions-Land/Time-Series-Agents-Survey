# Editorial trial v2 — Figures 4, 7 and 9

Second iteration of the restrained navy/terracotta style. Comic Sans MS is used for selected headings, with Arial retained for explanatory labels. Gradients and soft shadows are limited to selected windows, time axes and functional objects. Data signals remain flat black. Scientific content and geometry are preserved.

Each PPTX contains one slide and preserves native nested groups, editable text, shapes, curves and tables. Isolated raster icons remain raster images within groups; their interior pixels are not individually editable. Original v1 files are preserved.

`Figures_04_07_09_V1_vs_V2.pdf` compares v1 (left) and v2 (right). Individual PDF exports are in `pdf/`; editable files are in `pptx/`. `refine.py` records the OOXML edits and `changes.json` records selected changes. Production manuscript references are unchanged.

Validation: package integrity, geometry checks and Artifact Tool import passed for all three PPTX files. PDF exports and comparison pages were visually inspected. No GitHub or Overleaf synchronization performed for this trial.
