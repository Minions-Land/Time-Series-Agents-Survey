# Xu et al. agentic-forecasting snapshot

`agentic-forecasting-systems.csv` records the systems in Tables 1 and 5 of
Xu et al., *LLM-Based Agents for Forecasting and Prediction*, whose reported
control flow includes refinement, multiple agents, executable tools or code,
search, debate, memory-driven control, or an explicit agent benchmark. The
one-pass model and prompt rows in the same tables are not transcribed here.
This file supports candidate discovery only; original-paper review decides
membership in our corpus.
