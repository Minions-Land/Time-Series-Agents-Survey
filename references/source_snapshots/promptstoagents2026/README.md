# From Prompts to Agents high-autonomy snapshot

`high-autonomy-papers.csv` contains all 40 records coded as L3 Orchestrator or L4 Multi-Agent in the companion repository's `data/coded_papers.csv`. The source was commit `81a2e8eff2c46dec70e46181f0a01bc8deacd9a0`, inspected on 2026-09-10. The upstream corpus contains 369 coded papers and derives from 1,664 canonical search results across DBLP, arXiv, and Google Scholar. This snapshot is candidate-discovery evidence; the upstream autonomy code does not replace our scope, claim, Harness, or Google Scholar BibTeX review.
