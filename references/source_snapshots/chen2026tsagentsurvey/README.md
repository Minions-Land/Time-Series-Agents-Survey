# Chen et al. source snapshot

This directory contains the two source files needed to reproduce the coverage
audit for Table 3 of Chen et al., *LLM Agents for Time-Series: A Survey*
(arXiv:2608.26226):

- `appendix_02_methods.tex`: the 47-system table and its citation keys.
- `custom.bib`: the corresponding bibliographic records supplied by the paper.

The files were downloaded from the official arXiv source package on
2026-09-10. They provide identity evidence for the coverage comparison; they
do not establish Google Scholar verification for records absent from the
production bibliography.
