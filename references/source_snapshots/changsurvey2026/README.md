# Chang et al. agentic-system snapshot

`agentic-systems.csv` transcribes every research-paper row whose `T-Agent`
value is non-zero in Tables 4 and 5 of Chang et al., *A Survey of Reasoning and
Agentic Systems in Time Series with Large Language Models* (TMLR 2026). Table
3 contains no non-zero `T-Agent` rows. Titles were resolved against the paper's
reference list. This is candidate-discovery evidence, not our inclusion or
Google Scholar verification decision.
